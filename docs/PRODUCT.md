# Product

## Vision

Kenzo is a funnel builder SaaS for coaches selling $400–$1000+ offers. It blends two approaches:

- **Clyro** (clyro.io): Template-driven funnel editor — pick a template, customize blocks, publish. Fast, deterministic, always works.
- **OpBot**: Conversational AI that interviews the user and builds the funnel for them — asks questions about niche, offer, audience, then emits a complete funnel.

## Target user

Coaches and course creators who:
- Sell high-ticket offers ($400–$1000+)
- Are NOT technical — they can't/won't build pages from scratch
- Want speed: "I need a funnel live today"
- Want quality: "I need it to convert, not just exist"
- Want control: "I need to tweak every word, every color"

## User journey (north star)

1. **Log in** → Dashboard → see your funnels (cards with status, preview thumbnail)
2. **Create funnel** → land in **live-chat split-screen**: AI chat on LEFT asks questions; funnel builds **live** on RIGHT. When build is done, full editor appears for fine edits.
3. **Click existing funnel** → **funnel detail** screen → choose **Edit funnel** or **View Insights**
4. **Insights** = traffic/conversion + speed + lead-pipeline value + page load speed
5. **Owner can edit everything** — every block, setting, theme, AI value. No locked sections.

## Glossary

| Term | Definition |
|------|------------|
| **Funnel** | A published landing page that converts visitors into leads/applications |
| **Block** | A single section or element on a funnel page (hero, ticker, cards, FAQ, CTA, etc.) |
| **IC Section** | "Inner Circle" section — a full-width theme-aware funnel section (ic-hero, ic-ticker, etc.) |
| **Business Profile** | User's business context stored in `business_profiles` — niche, offer, audience, pricing, tone |
| **Template** | A pre-built block sequence (Waitlist, Application, VSL, Agency) with seed props |
| **Live Build** | AI builds the funnel in real-time as user answers questions in chat |

## North-star metrics

- **Time-to-funnel**: From "create" click to published funnel < 5 minutes
- **Zero-crash**: Preview never whitescreens, even on malformed AI output
- **Conversion rate**: Published funnels convert at industry benchmark or better
- **Edit rate**: Users who enter editor actually publish (not abandon)

## Funnel archetypes

| Archetype | Use case | Key sections |
|-----------|----------|--------------|
| **Waitlist** | Pre-launch hype, email capture | Hero, Ticker, Cards (benefits), FAQ, CTA |
| **Application** | High-ticket qualification funnel | Hero, Ticker, Cards (system), Results, FAQ, Apply form |
| **VSL** | Video sales letter, long-form | Hero (with video), Cards (proof), FAQ, CTA |
| **Agency** | Service-based, portfolio | Hero, Cards (services), Results (case studies), FAQ, CTA |

## Monetization strategy

Users pay for:
- Funnel hosting + publishing
- AI builder credits (per build or subscription)
- Analytics/insights (premium tier)
- Lead pipeline CRM (premium tier)
